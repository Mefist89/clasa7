Primii pași în C++

Să descoperim tipurile de date și operațiile simple!

1 Ce tip de date este?

Alege tipul potrivit pentru fiecare valoare de mai jos.

2 Adunare, Scădere, Înmulțire cu numere întregi (int)

Calculează rezultatul folosind numere întregi (fără punct).

🍎 Ai 2 mere și mai primești 3. Câte ai în total?
int mere = 2;
int primite = 3;
int total = mere + primite;
1. Cât este 2 + 3?
🍬 Aveai 5 bomboane și ai mâncat 1. Câte au rămas?
int bomboane = 5;
int mancate = 1;
int ramase = bomboane - mancate;
2. Cât este 5 - 1?
📦 Ai 2 cutii, în fiecare sunt câte 2 jucării. Câte jucării ai?
int cutii = 2;
int jucarii_pe_cutie = 2;
int total = cutii * jucarii_pe_cutie;
3. Cât este 2 * 2?
3 Operații cu zecimale (float)

Acum calculăm numere cu punct (bani, greutate, lungime).

💰 Ai 1.5 lei și bunica îți mai dă 2.0 lei.
float bani = 1.5;
float bunica = 2.0;
float total = bani + bunica;
1. Cât este 1.5 + 2.0?
🍰 Aveai 5.5 lei și ai cumpărat o prăjitură de 1.5 lei.
float aveai = 5.5;
float ai_cheltuit = 1.5;
float au_ramas = aveai - ai_cheltuit;
2. Cât este 5.5 - 1.5?
🥖 Ai tăiat un baton de pâine de 6.0 bucăți în 2 părți egale.
float bucati = 6.0;
float parti = 2.0;
float rezultat = bucati / parti;
3. Cât este 6.0 / 2.0?
