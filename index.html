📖 Rezumat tipuri de date
int
Numere întregi — fără parte fracționară. Cantitate, număr, vârstă.
7 -3 100 0
float
Numere zecimale — cu punct. Preț, înălțime, temperatură.
3.14 1.75 99.9
char
Un singur caracter între ghilimele simple. Literă, cifră, semn.
'A' '5' '!' '+'
bool
Valoare logică: doar «da» sau «nu».
true false

💻 Exemple de programe în C++
PROGRAMUL 1 🛒 Bon de casă

Programul calculează costul cumpărăturilor și afișează bonul. Observă: cantitatea — int, prețul — float, totalul — tot float.

// Program: Bon de casă
#include <iostream>
using namespace std;

int main() {
    // Date despre produs
    int cantitate = 3;
    float pret = 45.5;
    bool reducere = false;
    char sectiune = 'A';

    // Calculăm totalul
    float total = cantitate * pret;

    cout << "=== BON ===" << endl;
    cout << "Sectiune: " << sectiune << endl;
    cout << "Cantitate: " << cantitate << endl;
    cout << "Pret unitar: " << pret << endl;
    cout << "Total: " << total << endl;
    cout << "Reducere: " << reducere << endl;

    return 0;
}
